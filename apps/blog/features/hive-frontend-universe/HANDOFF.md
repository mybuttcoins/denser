## 6. Invariants as actually enforced

- Deterministic world: everything seeds from the 30-minute window start via mulberry32; no Math.random in world building. `world.ts` MEASURES the invariants every build (0 crossings, max degree 4, minimum 35 degrees, junction spacing) and reports them in world.stats.
- Position is always edge + fraction. Nothing stores world x/y as source of truth. Rides, hazards and teleports never fake position: rides draw an overlay while the real position stays parked; the sock trip uses the ordinary placeAt.
- `movement.ts` is frozen. Abilities layer on top: oxygen tops up fuel AFTER jump(); slime scales the dt fed to the integrator; holds skip the integrator for a moment.
- No image assets. All art is code-drawn; the only bitmaps are real avatars through the app's proxy.
- The villain's player-visible name is exactly one translation key (`hive_frontend_universe.landmarks.json_keep`, value "Emperor J SON" in all nine locales). Code comments also mention the name but are never rendered.
- localStorage only through the TTL wrappers; helmet progress, visited places, witness cache all use them.
- Verified per pass: headless world checks across six seed windows, headless logic tests for hazards and the buzzing station, browser-harness screenshots, and frame-time minimums, reported in each commit message.

THE TWO-LAYER INTENT (Bryan's own words)
The game is two things wearing one skin. Layer one is a front end: a fun way
to move through the chain, where real landmarks have real links that open
real chain pages, and the human makes their own choices (vote, comment,
follow) in their own hands, never automatic. Layer two is pure game:
enemies, villain, ruins, tokens, living entirely inside the game, touching
the chain nowhere. Choose-your-own-adventure: explore as you wish, partake
in game elements if you choose. The chain is never spammed. Where the game
touches the chain is always deliberate and read-only unless the user
themselves chooses to act.
